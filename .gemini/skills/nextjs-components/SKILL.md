name: Next.js Components
description: Skill to create and modify Next.js components in the project
---

| Campo | Valor |
|-------|-------|
| **Trigger** | "componente", "página", "layout", "tab", "UI", "interfaz" |
| **Acción** | Guía para crear/modificar componentes Next.js en el proyecto |

**Contenido del skill:**
1. Componentes existentes: `Header`, `ImageGenerator`, `TextGenerator`, `TabSwitcher`, `Protected`
2. Plantilla para nuevos componentes (con `"use client"`, tipado, CSS modules)
3. Patrones de estado (AuthContext, custom hooks)
4. Estructura de rutas (App Router, `page.tsx`, `layout.tsx`)
5. Uso de `src/components/` y `src/styles/`
